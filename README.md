# ☁️ Shaun Wana — AWS Cloud & Data Engineering Journey

Welcome to my cloud journey.

I started my AWS journey through **AWS re/Start**, where I built my foundation in cloud computing and earned the **AWS Certified Cloud Practitioner** certification. Since then, my journey has evolved from learning AWS fundamentals to facilitating cloud training, working across AWS and Azure, developing SQL and analytics skills, earning the **AWS Solutions Architect – Associate**, and now moving deeper into **Data Engineering**.

This repository documents that progression, the technologies I have worked with, projects I am building, and my continued development toward becoming a cloud-focused Data Engineer.

## 👨🏾‍💻 About Me

I am a Cloud & Data Platform Training Facilitator with more than three years of experience delivering hands-on technical training across AWS, Azure and SQL.

Working as a facilitator has strengthened more than my ability to teach. It has required me to understand cloud concepts deeply enough to explain them, demonstrate them practically, troubleshoot problems, assess technical work and help learners connect AWS services to real business requirements.

My current focus is expanding that cloud foundation into **Data Engineering**, particularly data ingestion, transformation, storage, analytics and automation on AWS.
